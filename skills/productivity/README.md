# Productivity

General workflow tools, not code-specific.

- **[dm-loopify](./dm-loopify/SKILL.md)** - Generalized iterative optimization to any goal. Build a rubric, score the baseline, then improve the target until the score plateaus.
- **[dm-pocockify](./dm-pocockify/SKILL.md)** - Purpose-first workflow for creating, reviewing, or pocockifying agent skills. Use when the user wants to create a new skill, improve an existing skill, review a skill, or create a stronger pocockified version from an existing skill. Inspired by Matt Pocock.
