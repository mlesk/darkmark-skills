# Productivity

General workflow tools, not code-specific.

- **[loopify](./loopify/SKILL.md)** - Generalize iterative optimization to any goal. Instead of shipping the first draft, collaborate with the user to discover what "good" means for their artifact, and use that rubric to drive a directed optimization loop.
- **[pocockify](./pocockify/SKILL.md)** - Purpose-first workflow for creating, reviewing, or pocockifying agent skills. Use when the user wants to create a new skill, improve an existing skill, review a skill, or create a stronger pocockified version from an existing skill. Inspired by Matt Pocock.
